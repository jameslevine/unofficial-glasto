# unofficial-glasto

Unofficial Glastonbury companion app — monorepo with mobile (Expo), web (Next.js), backend (AWS CDK + Lambda), scraper, and shared packages.

## Agent skills

### Issue tracker

GitHub Issues at https://github.com/jameslevine/unofficial-glasto. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical roles, all using Matt's default strings (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
